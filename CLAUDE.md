# Claude Code project instructions

`AGENTS.md` at the repository root is the single source of truth for project rules. Read it before making changes and follow it; do not override or duplicate its policies here. Also follow `CONTRIBUTING.md` and the relevant project documentation, tests, and code.

Use a dedicated branch and submit a pull request. Never push directly to `main` or bypass branch protections. Do not expose credentials, weaken safety gates, or claim checks passed unless they were run and passed.
