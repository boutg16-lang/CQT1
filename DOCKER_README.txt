# OUSSAMA Cutter — one-command Docker setup (v7.20)
#
# 1) Install Docker Desktop: https://www.docker.com/products/docker-desktop/
# 2) From this folder:
#      docker compose up --build
# 3) Open http://localhost:7860
#
# Everything is bundled: Python 3.11, ffmpeg, yt-dlp, Whisper (CPU), OpenCV,
# Gradio WebUI. Videos land in ./VIRALS (kept between restarts).
#
# To stop: docker compose down
