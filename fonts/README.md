# fonts/

- `NotoKufiArabic-VF.ttf` — Noto Kufi Arabic variable font (weight 100-900),
  used at weight 900 ("Black") for Arabic headline text in
  `scripts/thumbnail_generator.py` (RTL + raqm shaping). Source: google/fonts
  (SIL OFL 1.1); license text appended in `OFL.txt`.
- `Cairo-*.ttf`, `Montserrat-*.ttf` — pre-existing bundled fonts (OFL).
