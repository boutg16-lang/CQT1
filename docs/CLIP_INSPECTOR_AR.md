# Clip Inspector — فحص المقطع قبل النشر

توفر الوحدة `scripts.pro_clip_review` تقريراً موحداً عن النص والعنوان والبيانات الوصفية والنص الظاهر داخل الفيديو وجودة الملف والصوت.

## التشغيل

```powershell
python -m scripts.pro_clip_review `
  --transcript "transcript.json" `
  --video "final_clip.mp4" `
  --title "العنوان المقترح" `
  --alternative-title "عنوان بديل موثق" `
  --caption "وصف المقطع" `
  --hashtag "أخبار" `
  --language ar `
  --ocr-frames 8 `
  --report "clip_review.json"
```

- `--transcript`: نص أو JSON للتفريغ. يجب أن يحتوي نصاً فعلياً.
- `--video`: ملف الفيديو النهائي؛ يفعّل OCR وفحص الملف والصوت.
- `--ocr-frames`: عدد الإطارات المأخوذة عينياً، من 1 إلى 24.
- `--no-ocr`: تعطيل OCR صراحةً؛ عند تمرير `--video` يحوّل التقرير إلى `review` ولا يُعدّ الفحص المرئي ناجحاً.
- `--no-media-qc`: تعطيل فحص FFprobe/FFmpeg التقني؛ عند تمرير `--video` يلزم فحص بشري بدلاً من اعتباره اجتيازاً.

## منطق القرار

- `blocked`: مخالفة عالية الثقة أو ملف غير صالح/دون مسار صوت.
- `review`: تعذر إكمال فحص، OCR غير متاح، عناوين غير موثقة، أو مشكلة جودة تحتاج قراراً بشرياً.
- `approved_for_human_signoff`: اجتازت الفحوص الآلية فقط؛ يبقى `human_signoff_required=true` و`publish_allowed=false` حتى الاعتماد البشري.

## فحوص الوسائط

- وجود ملف قابل للقراءة، مسار فيديو، مدة موجبة، ومسار صوت.
- قياس Integrated Loudness وTrue Peak عبر FFmpeg loudnorm.
- قياس الصمت الطويل عبر silencedetect.
- غياب FFprobe/FFmpeg أو فشل التحليل لا يتحول إلى نجاح صامت؛ تُطلب المراجعة.

## حدود التغطية

OCR يأخذ عينات زمنية ولا يقرأ كل إطار؛ كما أن دقة العربية واللهجات والنصوص الصغيرة تتأثر بجودة الصورة ومحرك Tesseract واللغات المثبتة. الفحص الدلالي الآلي ليس حكماً قانونياً أو ضماناً لقرار منصة يوتيوب. يجب مراجعة المقاطع الملتبسة يدوياً، خصوصاً الاقتباس الصحفي والتوثيق والإدانة الواضحة للتحريض.
