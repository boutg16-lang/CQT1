# OUSSAMA Cutter 7.6.0-pro

## ملخص الإصدار

هذا الإصدار يواصل تحويل OUSSAMA Cutter إلى خط إنتاج عملي للفيديو القصير، مع الحفاظ على التشغيل المحلي في Windows ودعم NVIDIA CUDA وWhisperX. تم التركيز في هذه الجولة على منع نتائج قديمة أو ناقصة، تحسين القرار الأمني قبل النشر، تثبيت تتبع المتحدث، ورفع وضوح واجهة WebUI العربية.

## أهم التحسينات

| المجال | التحسين |
|---|---|
| عدد المقاطع | إذا كان `viral_segments.txt` القديم يحتوي عدداً مختلفاً عن العدد المطلوب، يُعاد التحليل بدلاً من إعادة استخدام نتيجة قديمة؛ كما يبقى خيار `--force-new-segments` متاحاً لإعادة التوليد الصريح. |
| الأمان الدلالي | توسعت صيغ الكشف العربية للهجات والجمع وعبارات الإقصاء والتحريض، وتُحفظ توصية آمنة مع كل نتيجة للمراجعة البشرية. |
| بوابة الرفع | مسار WebUI يفحص الملف النهائي فعلياً عبر `ffprobe` قبل الاتصال بالمنصة، ويتحقق من وجود مسار فيديو صالح ومدة قابلة للنشر. |
| تتبع المتحدث | أضيف تنعيم زمني لنسبة فتح الفم، مع اعتماد أكثر تحفظاً على طاقة الصوت حتى لا ينتقل الإطار بسبب لقطة أو ضجيج منفرد. |
| جودة الصوت | تمت إضافة تطبيع مقاوم للضجيج في تحليل الطاقة، وlimiter بعد مزج الموسيقى مع auto-duck لتقليل clipping. |
| مراجعة المقاطع | يعرض جدول WebUI الآن حالة السلامة، سبب الحجب أو المراجعة، والبديل المقترح قبل القص أو الرفع. |
| العربية والهوية | تحسنت بطاقات الإرشاد وRTL وتنسيق جدول المراجعة، وأصبح عنوان الصفحة OUSSAMA Cutter مع رفع الإصدار إلى `7.6.0-pro`. |

## تشغيل Windows الموصى به

من مجلد المشروع على القرص D شغّل PowerShell بصلاحية تنفيذ مؤقتة عند الحاجة، ثم نفّذ:

```powershell
cd D:\SS
Set-ExecutionPolicy -Scope Process Bypass
.\setup_on_d.ps1 -Mode Full -Transcription gpu
.\run_webui.bat
```

بعد الإقلاع، راجع بطاقة **حالة التفريغ والجهاز**. يجب أن تظهر نسخة Torch CUDA وأن تكون CUDA متاحة واسم بطاقة NVIDIA ظاهرًا. عند امتلاك RTX 3060 اختر `Auto` أو `NVIDIA GPU / CUDA`؛ اختر CPU فقط عند الحاجة إلى تفريغ لا يستخدم البطاقة.

## الأمان قبل YouTube

الوضع الموصى به هو **حظر المقاطع المخالفة** مع إبقاء **المراجعة الإضافية بالذكاء الاصطناعي** مفعلة. الحماية ليست ضماناً مطلقاً لقبول المنصة؛ فهي تقلل المخاطر عبر فلتر محلي، تحليل دلالي، مراجعة اختيارية، بطاقة مخاطر، وبوابة رفع إجبارية. يجب مراجعة `safety_report.json` و`risk_scorecard.json` وبيانات العنوان والوصف قبل النشر العام.

> لا تستخدم وضع `flag` أو `off` للنشر الآلي إلا إذا كنت ستراجع كل مقطع بنفسك. وضع `censor` يكتم الكلمات التي يمكن تحديدها زمنياً، لكنه لا يحوّل سياقاً خطراً إلى محتوى آمن تلقائياً.

## التحقق المنفذ

اجتاز الإصدار اختبارات `pytest` الكاملة، وفحص `ruff check .`، وفحص `python3 -m compileall -q .`، وفحص JSON لملفات الترجمة. كما تم تشغيل WebUI محلياً والتحقق من استجابة صفحة OUSSAMA Cutter على المنفذ 7860.

## ملاحظة ترقية

يجب نسخ المشروع القديم احتياطياً قبل استبداله. لا تنسخ مجلد `.venv` أو `models` إلى الأرشيف؛ ثبّت الاعتماديات على Windows عبر المثبت المرفق، واترك مفاتيح Gemini وملف OAuth خارج الأرشيف أو أدخلها من الواجهة عند الحاجة.
