## الجديد: corpus عربي مرخّص لمعايرة Audio QC

آخر بند مفتوح من تحليل الفجوات: العتبات الافتراضية لـ Audio QC قيم بث عامة،
والمطلوب عتبات **مُعايَرة على صوت عربي مرخّص**. أصبحت سلسلة الأدوات مكتملة:

```
audio_qc_corpus.py (جديد)   →  corpus بإثبات ترخيص
audio_qc_calibrate.py (موجود) →  قياس + عتبات بالمئينات
audio_qc --thresholds-file   →  تطبيق العتبات على الإنتاج
```

### `scripts/audio_qc_corpus.py`

| الأمر | الدور |
|---|---|
| `init <dir> --source .. --license ..` | إنشاء corpus بـ `corpus_manifest.json` (ترخيص معروف إلزامي: `own-recording` / `cc0` / `cc-by-4.0` / `custom` مع ملاحظة) |
| `add <dir> <ملفات...>` | تطبيع أي صوت/فيديو إلى MP4 معياري صغير (إطار أسود 1fps + أحادي 16kHz AAC) |
| `import-cv <dir> <تصدير Common Voice>` | استيراد العربية من التخطيط الرسمي (CC0) مع manifest تلقائي |
| `status <dir>` | ملخص الجاهزية (يحتاج 5 مقاطع قابلة للقياس) |
| `calibrate <dir>` | **يفشل مغلقاً بلا ترخيص**، ثم ينتج `audio_qc_thresholds.json` |

### فلسفة الترخيص

- **لا تنزيل تلقائي لأي dataset:** موافقة الشروط قرار بشري. المصدر الموصى به:
  تسجيلات القناة الخاصة (بلا أي مشكلة ترخيص، والأدق لصوتك).
- **الفشل مغلقاً:** لا معايرة على بيانات مجهولة الترخيص — نفس فلسفة
  `scripts/provenance.py` في النشر.

### التحقق الفعلي

- 11 اختباراً حقيقياً بـ FFmpeg (ترخيص، تطبيع، استيراد CV من تخطيط مُقلَّد،
  معايرة طرف-لطرف داخل حدود الأمان).
- تحقق يدوي: thresholds الناتج يُستهلك عبر `audio_qc.load_thresholds` ويؤثر
  فعلاً في نتيجة القياس.

الدليل: `docs/AUDIO_QC_CORPUS_AR.md`.
