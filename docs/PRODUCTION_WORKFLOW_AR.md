# مسار الإنتاج والمراجعة الموحد — OUSSAMA Cutter

## ما الذي يفعله؟

يجمع `scripts/production_workflow.py` مراحل التحليل التحريري المتاحة في المشروع في تقرير واحد:

1. تحليل مؤشرات الحوار العربي واللهجات المغاربية الشائعة مع أدلة نصية.
2. اقتراح نافذة زمنية أوسع حول اللحظة مع إبقاء التوقيت الأصلي دون تغيير.
3. ترتيب المرشحين وتجميع حزمة متنوعة مع أسباب الاستبعاد.
4. إضافة سياق استمرار المتحدث عند توفر `speaker_id` وتوقيتات متجاورة.
5. تشغيل بوابة التحقق النهائية على المقاطع المختارة.
6. فحص صوت الملفات المصدرة اختيارياً عبر FFmpeg/FFprobe باستخدام وحدة `audio_qc`.
7. إخراج تقرير JSON قابل للأرشفة والمراجعة.

## التشغيل

من جذر المشروع:

```powershell
.\.venv\Scripts\python.exe -m scripts.production_workflow .\segments.json --output .\VIRALS\production_report.json --limit 8 --max-per-topic 2 --min-duration 15 --max-duration 90
```

لفحص ملفات فيديو تم تصديرها بالفعل:

```powershell
.\.venv\Scripts\python.exe -m scripts.production_workflow .\segments.json --output .\VIRALS\production_report.json --rendered-media .\VIRALS\cuts\clip_01.mp4 .\VIRALS\cuts\clip_02.mp4
```

بعد تثبيت الحزمة يمكن استخدام:

```powershell
oussama-cutter-production .\segments.json --output .\production_report.json
```

## شكل الإدخال

يمكن أن يكون الملف قائمة JSON مباشرة أو كائناً يحوي `segments`:

```json
{
  "segments": [
    {
      "id": "clip-001",
      "start": 12.4,
      "end": 48.2,
      "text": "واش السبب؟ عندي الدليل... والخلاصة واضحة.",
      "score": 87,
      "topic": "نقاش سياسي",
      "speaker_id": "SPEAKER_00"
    }
  ]
}
```

الحقول `start`, `end`, `text` أو `transcript_text` أساسية للاستفادة من التقييم. `speaker_id` و`topic` و`score` اختيارية. لا ينشئ المحرك هوية المتحدث؛ يستفيد من معرفات diarization التي ينتجها المسار الأساسي عند توفرها.

## قواعد السلامة والجودة

- لا يوجد نشر تلقائي ولا اعتماد تلقائي: كل مقطع يبقى `human_review_required`.
- نتائج المؤشرات اللغوية ليست فهماً دلالياً كاملاً ولا حكماً على صحة الادعاءات.
- التوقيت المقترح ليس بديلاً عن الاستماع إلى بدايات ونهايات المقطع.
- فحص الصوت اختياري ويحتاج FFmpeg وFFprobe؛ لا يثبت جودة الصورة أو صحة الترجمة.
- فشل بوابة المقطع أو وجود عائق صوتي يعطي حالة `blocked` ويجب معالجة السبب.
- لا يحذف التقرير المرشحين المستبعدين؛ يعرض سبب الاستبعاد.

## حدود هذه الجولة

هذا مسار موحد قابل للتشغيل من CLI، وليس بديلاً عن تنفيذ المعالجة الأساسية أو عن اختبار WebUI/RTX 3060. لم يتم اختبار رفع YouTube أو جدولة النشر. يلزم اختبار قبول على فيديو فعلي من جهاز Windows المستهدف قبل اعتماد إصدار إنتاجي.
