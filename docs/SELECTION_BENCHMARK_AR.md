# قياس جودة الاختيار — selection_benchmark

> **لماذا؟** طبقات الترتيب (clip_scoring، تحليل الخطاف، عقوبة التكرار، أرضية
> التحرير، إزالة التكرار) كلها مُختبَرة منفردة، لكن تأثيرها المشترك كان يُضبط
> بالحدس. هذه الأداة تستبدل الحدس بمقياس: **recall@k — كم لحظة ذهبية
> (موسومة بشرياً) تنجو إلى أعلى k نواتج من مسار الاختيار الحقيقي.**

## التشغيل الفوري

```powershell
python -m scripts.selection_benchmark --demo
```

fixture تجريبي مدمج (حديث 10 دقائق: 3 لحظات قوية + حشو) — يجب أن يعطي
`recall@6 = 1.0` واللحظات الذهبية في المراتب الثلاث الأولى. أي تعديل مستقبلي
على منطق الترتيب يُقاس ضده.

## بناء fixture حقيقي من فيديوهاتك

1. **فرّغ الفيديو** (أي backend) إلى قائمة جمل بتوقيتات.
2. **وسّم اللحظات الذهبية:** شاهد الفيديو وسجّل 3–5 نوافذ (`start`/`end`)
   التي كنت ستقصّها فعلاً — هذا هو الحكم البشري.
3. **وفّر المرشحين:** النوافذ الخام التي اقترحها النموذج (من `viral_segments.txt`
   قبل الترتيب) أو نوافذ ثابتة كل 30 ثانية.

```json
{
  "name": "podcast-ep12",
  "transcript": [{"start": 0.0, "end": 2.5, "text": "..."}],
  "candidates": [{"start_time": 30, "end_time": 60, "title": "...", "text": "...", "score": 8}],
  "gold": [{"start": 184, "end": 214}, {"start": 512, "end": 545}]
}
```

ثم:

```powershell
python -m scripts.selection_benchmark --fixture my_fixture.json -k 5 --output bench.json
```

## قراءة النتائج

| المقياس | المعنى |
|---|---|
| `recall@k` | نسبة اللحظات الذهبية التي لها ناتج في أعلى k يغطي ≥50% منها |
| `best_rank` | رتبة أول ناتج يغطي الذهبية (`null` = ضاعت) |
| `coverage` | كم من الذهبية غطّاه أفضل ناتج |

## كيف تضبط الطبقات به

1. ثبّت 5–10 fixtures من محتواك الحقيقي (أنواع مختلفة: بودكاست، تعليمي، ردود).
2. شغّل القياس وسجّل recall@k كخط أساس.
3. كل تعديل على الأوزان/العتبات (`performance_weights.py`، أرضية التحرير،
   `VIRALCUTTER_MIN_FINAL_SCORE`) يُقبل فقط إن **لم يهبط recall@k** على
   المجموعة — ويُرفض إن أنزل ذهبية إلى خارج أعلى k.

## حدوده

- يقيس المسار **الحتمي** (بلا LLM ولا editor review) — طبقة المراجعة الاختيارية
  تُقاس لاحقاً بfixtures منفصلة.
- الوسم البشري هو مصدر الحقيقة؛ 3 ذهبيات لكل فيديو كافية لبدء الضبط.
