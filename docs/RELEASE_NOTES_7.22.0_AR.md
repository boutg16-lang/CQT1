# إصدار 7.22.0-pro — عناوين SEO ذكية + جدولة النشر التلقائي

تاريخ الإصدار: 2026-08-23

## 🧠 محرك عناوين SEO (جديد)

- **`scripts/seo_titles.py`**:
  - **جلب اقتراحات يوتيوب**: يستخدم واجهة الاقتراحات العامة من يوتيوب
    (بدون مفتاح API) — اعرف ماذا يبحث الناس حول موضوعك:
    `python scripts/seo_titles.py suggest "كسب المال من الانترنت"`
  - **تقييم شفاف (0-100)**: يكافئ قوة الخطاف، وجود الكلمات المفتاحية،
    طول العنوان المثالي (35-70 حرفاً)، ونمط السؤال/الرقم؛ ويعاقب
    الكتابة بالأحرف الكبيرة وحشو الكلمات:
    `python scripts/seo_titles.py score "عنوانك هنا" --keyword "كلمة"`
  - **توليد عناوين مرتّبة**: قوالب عربية ذكية + كلمات مفتاحية + زاوية →
    عناوين مقترحة مرتبة بالدرجة:
    `python scripts/seo_titles.py generate "الربح من الانترنت" --count 6`
  - **أفضل أوقات النشر**: جدول أوقات تفاعل متحفظ (يوتيوب/تيك توك/ريلز):
    `python scripts/seo_titles.py slots --platform youtube --count 5`

## 🗓️ جدولة النشر التلقائي (جديد)

- **`scripts/publish_scheduler.py`**:
  - **بناء خطة نشر**: وزّع M مقطعاً على أفضل الأوقات في الأيام القادمة
    (مع دعم ساعاتك المفضلة عبر `--user-hours 17 18 19`):
    ```
    python scripts/publish_scheduler.py --videos clip1.mp4 clip2.mp4 \
        --project VIRALS/مشروعي --platform youtube --days 7
    ```
  - **توليد ملف الخطة** `publish_schedule.json` ثم تنفيذها:
    ```
    python scripts/publish_scheduler.py --plan VIRALS/مشروعي/publish_schedule.json --dry-run
    ```
  - **Daemon حقيقي**: ينتظر كل موعد ثم يرفع المقطع عبر `stream_upload_batch`
    (نفس بوابة الأمان الكاملة) — مع `--dry-run` للاختبار الآمن.
  - جدولة يوتيوب تتطلب `privacy=private` تلقائياً (كما يفرض يوتيوب).
