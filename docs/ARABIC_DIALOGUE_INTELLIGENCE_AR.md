# ذكاء الحوار العربي — إضافة تجريبية قابلة للمراجعة

## الهدف
إضافة طبقة تفسيرية تكشف مؤشرات لغوية ظاهرة في التفريغ العربي واللهجات المغاربية الشائعة: السؤال، الاعتراض، الرد، الإشارة إلى كشف/معلومة، الخلاصة، والدعوة إلى التفاعل.

## الملفات
- `scripts/arabic_dialogue_intelligence.py`: المحلل وواجهة CLI.
- `tests/test_arabic_dialogue_intelligence.py`: اختبارات الوحدة.

## الاستخدام
```powershell
.\.venv\Scripts\python.exe -m scripts.arabic_dialogue_intelligence cuts.json --output dialogue_analysis.json
```
يدعم ملف JSON على شكل قائمة مقاطع أو كائن يحتوي `segments`. يقرأ النص من `transcript_text` أو `text`.

## حدود مهمة
هذه مطابقة عبارات قابلة للتفسير وليست فهماً دلالياً كاملاً أو حكماً على صدق الكلام أو انتشاره أو مخالفته لسياسات يوتيوب. كل إشارة تعرض الكلمات التي أدت إلى اكتشافها. لا تُعدّل هذه الإضافة درجات الانتشار ولا تختار المقاطع تلقائياً؛ يجب مراجعة السياق الصوتي والمرئي قبل النشر.
