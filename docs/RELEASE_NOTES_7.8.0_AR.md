# ملاحظات إصدار OUSSAMA Cutter 7.8.0-pro

## اختيار الملفات من الكمبيوتر

أصبح قسم **جودة المونتاج** عملياً دون كتابة مسارات يدوياً. يمكن اختيار ملف الموسيقى الخلفية، فيديو B-Roll، عدة مؤثرات صوتية، وشعار القناة مباشرة من الكمبيوتر. يملأ WebUI المسار المستخدم في خط CLI تلقائياً، مع إبقاء خانة المسار اليدوي للحالات المتقدمة.

أضيف كذلك اختيار ملف نموذج ONNX للفحص البصري وقاعدة الموسيقى JSON من الكمبيوتر. اختيار ملفات المؤثرات المتعددة يحدد المجلد المشترك تلقائياً، بينما يبقى المسار اليدوي متاحاً إذا كانت المؤثرات موزعة في مجلد مختلف.

## تسجيل الدخول إلى YouTube

أعيد تنظيم تسجيل الدخول داخل تبويب **Publish & Upload**. يستطيع المستخدم اختيار ملف Google OAuth `client_secrets.json` مباشرة، ثم:

| الإجراء | النتيجة |
|---|---|
| حفظ/التحقق من الملف | يتحقق من بنية OAuth ويحفظ نسخة خاصة محلياً دون طباعة الأسرار |
| استبدال client_secrets | يحفظ الملف الجديد ويبطل التوكن القديم لإجبار تسجيل دخول جديد |
| تسجيل الدخول إلى YouTube | يبدأ تدفق OAuth الحقيقي دون رفع فيديو، ثم يحفظ التوكن المحلي |
| رفع/جدولة | يمرر الفيديو عبر بوابة الأمان، ثم يرفع أو يجدول حسب الخصوصية والوقت |

التوكن لا يُحفظ في المشروع ولا داخل الأرشيف. الإعداد الافتراضي للرفع يبقى `private`، ويجب استخدام `public` بعد مراجعة المستخدم للمقطع وبطاقة المخاطر.

## إصلاحات الأمان والتشخيص

أضيفت رسائل عربية عند غياب متطلبات Google OAuth، كما أصبح سجل الرفع يميز سبب منع الفحص البصري عن أخطاء الميتاداتا أو ملف الفيديو. لا تُعرض قيم `client_secret` أو مفاتيح API في سجل التشغيل.

## حدود OAuth

ملف `client_secrets.json` يجب أن يكون من Google Cloud Console لتطبيق OAuth مناسب، ويفضل Desktop app لتدفق `InstalledAppFlow`. اختيار الملف لا يمنح صلاحيات إضافية وحده؛ الصلاحيات تُمنح في شاشة Google ويُحفظ التوكن بعد موافقة المستخدم. عند اختيار الصلاحيات الكاملة يجب استخدام ذلك فقط عند الحاجة الفعلية.
