# دليل اختيار الملفات وتسجيل الدخول إلى YouTube

## اختيار الملفات في جودة المونتاج

افتح WebUI ثم انتقل إلى **إنشاء مشروع → المونتاج الاحترافي والمنصات**. فعّل **Professional polish** إذا كنت تريد تطبيق القفزات والتقريب والموسيقى والشعار بعد المونتاج الأساسي.

| العنصر | الإجراء |
|---|---|
| الموسيقى الخلفية | اضغط اختيار ملف الموسيقى، وحدد MP3 أو WAV أو M4A. سيُملأ المسار تلقائياً. |
| فيديو B-Roll | اضغط اختيار فيديو B-Roll وحدد MP4 أو MOV أو WebM. |
| المؤثرات الصوتية | اختر عدة ملفات صوتية؛ سيحدد النظام المجلد المشترك تلقائياً. |
| شعار القناة | اختر PNG أو JPG أو JPEG مباشرة. يفضل PNG بخلفية شفافة. |
| نموذج الفحص البصري | اختر ملف `.onnx` محلياً إذا كان لديك نموذج مخصص. |
| قاعدة الموسيقى | من تبويب النشر اختر ملف JSON الخاص بقاعدة البصمات. |

بعد الاختيار، يمكنك مراجعة المسار الذي ظهر في خانة النص وتعديله يدوياً. اختيار الملف لا يفعّل **Professional polish** تلقائياً؛ يجب تفعيل الخيار بنفسك حتى لا تتغير نتائج المشاريع القديمة دون قصد.

إذا اخترت مؤثرات من مجلدات مختلفة، اكتب مسار مجلد واحد يضم كل المؤثرات يدوياً. ويجب عدم اختيار ملف من مجلد مؤقت سيتم حذفه قبل انتهاء المعالجة.

## تجهيز Google Cloud

من Google Cloud Console أنشئ مشروعاً أو استخدم مشروعاً قائماً، فعّل **YouTube Data API v3**، ثم أنشئ OAuth Client ID من نوع Desktop app ونزّل JSON. لا تعِد تسمية الملف أو تعدّل قيم `client_id` و`client_secret` يدوياً.

## حفظ ملف client_secrets

في تبويب **Publish & Upload**:

1. اختر المشروع والمقطع.
2. افتح قسم **تسجيل الدخول إلى YouTube عبر OAuth**.
3. اضغط حقل ملف `client_secrets.json` واختر الملف من الكمبيوتر.
4. اضغط **حفظ/التحقق من الملف**.
5. راجع حالة OAuth؛ يجب أن ترى أن الملف محفوظ وأن التوكن قد لا يكون موجوداً بعد.

يُنسخ الملف إلى مخزن خاص محلياً تحت مجلد إعدادات المستخدم، ولا تظهر قيمة السر في سجل WebUI. لا تضع الملف داخل مجلد `VIRALS` ولا داخل الأرشيف ولا في Git.

## تسجيل الدخول الفعلي

بعد حفظ الملف اضغط **تسجيل الدخول إلى YouTube**. سيفتح Google صفحة الموافقة في المتصفح. وافق بالحساب الصحيح، ثم أغلق الصفحة بعد نجاح العودة. يحفظ النظام التوكن محلياً ويظهر مساره في حالة OAuth.

عملية تسجيل الدخول لا ترفع فيديو. الرفع لا يبدأ إلا عند الضغط على **Upload / Schedule**، وبعد مرور المقطع عبر بوابة الأمان وفحص الملف والميتاداتا.

إذا ظهرت رسالة نقص مكتبات Google، نفّذ من PowerShell داخل `D:\SS`:

```powershell
cd D:\SS
.\.venv\Scripts\python.exe -m pip install -r requirements-upload.txt
```

ثم أعد تشغيل `run_webui.bat`.

## استبدال client_secrets

عند تغيير مشروع Google Cloud أو إنشاء OAuth Client جديد:

1. اختر ملف `client_secrets.json` الجديد.
2. اضغط **استبدال client_secrets**.
3. سيحفظ النظام الملف الجديد ويبطل التوكن القديم.
4. اضغط **تسجيل الدخول إلى YouTube** مرة أخرى.

إبطال التوكن القديم مقصود؛ لأن إعادة استخدامه بعد تغيير عميل OAuth قد تؤدي إلى جلسة مرتبطة بإعداد سابق أو نطاقات غير متوقعة. لا تضغط الاستبدال لمجرد تحديث حالة الواجهة إذا كنت لا تريد إعادة تسجيل الدخول.

## الخصوصية والجدولة

ابدأ دائماً بـ `private` أو Dry Run. استخدم `unlisted` للمراجعة الخارجية، ولا تستخدم `public` إلا بعد مراجعة الفيديو والتقرير `risk_report.html`. وقت الجدولة يجب أن يكون بصيغة ISO 8601 وأن يحتوي على منطقة زمنية، وأن يكون في المستقبل.

> وجود client_secrets صحيح لا يعني أن YouTube سيقبل الفيديو أو أن الصلاحيات تسمح بكل العمليات. الملف يعرّف تطبيق OAuth فقط، بينما حساب Google يقرر الموافقة والنطاقات.

## استكشاف الأخطاء

إذا ظهر أن الملف غير صالح، تحقق من أنه يحتوي على كائن `installed` أو `web` وحقول `client_id` و`client_secret` و`auth_uri` و`token_uri`. إذا ظهر أن التوكن غير صالح، استعمل **استبدال client_secrets** ثم سجّل الدخول من جديد. وإذا توقف الرفع قبل الاتصال بالمنصة، افتح سجل الرفع وراجع سبب بوابة الأمان أو `publish_blocklist.json`.
