# إضافة تحريرية — مخطط حزم المقاطع

## الميزة الجديدة
أضيف `scripts/clip_package.py` لتجميع أفضل المرشحين في حزمة متنوعة للنشر المتتابع.

### السلوك
- ترتيب حسب الدرجة التحريرية ثم درجة الانتشار.
- حد أقصى اختياري للمقاطع من الموضوع الواحد.
- منع تداخل المقاطع من المصدر نفسه، مع حد أدنى اختياري للفاصل الزمني.
- تقليل التكرار النصي عبر تشابه Jaccard.
- سجل استبعاد يوضح سبب عدم اختيار كل مرشح.
- لا تعديل على بيانات المرشحين الأصلية، ولا حذف، ولا اتصال خارجي.

### الاختبارات
أضيفت ستة اختبارات تغطي سقف الموضوع، تداخل التوقيت، تكرار التفريغ، عدم تغيير المدخلات، والتحقق من الخيارات وهوية المصدر. اجتازت مجموعة المشروع الكاملة: 2,223 اختباراً ناجحاً و2 متجاوزان.

### الحدود
الميزة مستقلة وقابلة للاستدعاء من CLI أو دمجها لاحقاً في واجهة المراجعة. لم يتم الادعاء بأنها مدمجة تلقائياً في WebUI أو أنها تتنبأ بالانتشار.
