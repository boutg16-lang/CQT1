# اختبار الواجهة بمتصفح حقيقي (E2E) — WebUI Smoke Test

أداة `scripts/webui_e2e_smoke.py` تشغّل الواجهة، تفتحها بمتصفح حقيقي (Chrome)،
تنقر كل التبويبات، تأخذ لقطات شاشة، وتجمع أخطاء الـ console في تقرير — لإثبات أن
الواجهة **تعمل فعلاً على جهازك** بلا الحاجة إلى مشاركة شاشة.

> لا تنشر ولا ترفع أي شيء، ولا تلمس أي مفاتيح. كل ما تفعله: تحميل الواجهة المحلية والنقر.

## المتطلبات (مرة واحدة)
```bash
pip install playwright
```
لا حاجة لتنزيل متصفح: الأداة تستخدم **Chrome المثبّت لديك** (`channel="chrome"`).
إن لم يكن Chrome موجوداً: `playwright install chromium`.

## التشغيل — على جهازك (Windows)

**الخيار 1 — اترك الأداة تُقلع الواجهة (الأسهل):**
```powershell
cd D:\SS
.\.venv\Scripts\python.exe -m scripts.webui_e2e_smoke --launch --headed
```
`--headed` يُظهر نافذة المتصفح وأنت تراه ينقر التبويبات. احذفها للتشغيل الصامت.

**الخيار 2 — شغّل الواجهة أولاً ثم افحصها:**
```powershell
# نافذة أولى:
.\.venv\Scripts\python.exe main_improved.py --webui
# نافذة ثانية:
.\.venv\Scripts\python.exe -m scripts.webui_e2e_smoke --url http://127.0.0.1:7860
```

## المخرجات (`webui_smoke/`)
| الملف | الوصف |
|---|---|
| `report.md` | تقرير مقروء: النتيجة، التبويبات، أخطاء الـ console |
| `report.json` | نفس التقرير آلياً (للأرشفة/المقارنة) |
| `tab_00_home.png` … | لقطة لكل تبويب |
| `webui.log` | سجل تشغيل الواجهة (عند استخدام `--launch`) |

## معنى أكواد الخروج
| الكود | المعنى |
|---|---|
| `0` | سليم — الواجهة أقلعت وكل التبويبات فُتحت بلا أخطاء |
| `1` | توجد أخطاء صفحة/console (راجع `report.md`) |
| `2` | Playwright غير مثبَّت |
| `3` | الواجهة لم تستجب (راجع `webui.log`) |

## خيارات
```bash
python -m scripts.webui_e2e_smoke --help
#   --url            عنوان الواجهة (افتراضي http://127.0.0.1:7860)
#   --out            مجلد المخرجات (افتراضي webui_smoke)
#   --launch         إقلاع الواجهة قبل الفحص
#   --headed         إظهار نافذة المتصفح
#   --launch-timeout ثواني انتظار الإقلاع (افتراضي 180)
#   --max-tabs       حد أقصى للتبويبات (افتراضي 20)
```

## ماذا يعني «سليم»؟
- وجود `.gradio-container`، وعنوان الصفحة `OUSSAMA Cutter`.
- نجاح النقر على كل تبويب (`button[role="tab"]`).
- صفر أخطاء console وصفر أخطاء صفحة.
