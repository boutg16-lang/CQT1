# مخطط حزمة المقاطع التحريرية

أضيفت وحدة `scripts/clip_package.py` لإنشاء حزمة متوازنة من أفضل المقاطع بدلاً من تصدير مجموعة متكررة من نفس الفكرة.

## ما الذي تفعله؟
- ترتب المرشحين حسب `selection_score` ثم `score` مع ترتيب ثابت عند التعادل.
- تضع سقفاً لعدد المقاطع من الموضوع الواحد.
- تمنع اختيار مقطعين متداخلين زمنياً من المصدر نفسه.
- تكتشف تشابه نصوص التفريغ لتقليل التكرار حتى عندما تختلف التوقيتات.
- تنتج قائمة مختارة وقائمة مستبعدة مع سبب واضح لكل استبعاد؛ لا تحذف أي مرشح من ملف المصدر ولا تعدّل المدخلات.
- تعمل محلياً دون API أو اتصال إنترنت.

## الاستخدام
```powershell
.\.venv\Scripts\python.exe -m scripts.clip_package segments.json --output package.json --limit 5 --max-per-topic 2
```

يدعم الإدخال قائمة JSON مباشرة أو كائناً يحتوي `segments`. الحقول المفيدة: `selection_score`, `score`, `topic` أو `theme`, `transcript_text` أو `text`, `source_id`, `start`, `end`.

## حدود الميزة
هذه طبقة تنظيم تحريرية حتمية وليست نموذجاً يتنبأ بالانتشار. تشابه النصوص يعتمد Jaccard على الكلمات، لذلك لا يكتشف كل إعادة صياغة دلالية. يجب إبقاء قرار المونتاج النهائي للمراجع البشري.
