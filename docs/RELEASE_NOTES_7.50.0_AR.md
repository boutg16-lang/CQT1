## 1) دبلجة متعددة اللغات — `scripts/dubbing.py`

**الفجوة:** الترجمات تُترجم لكن الصوت يبقى عربياً، فالمقطع لا يصل جمهوراً آخر إلا مكتوباً.

| المزوّد | الشبكة | متى تستخدمه |
|---|---|---|
| `edge` (Microsoft Edge TTS) | **نعم — يرسل النص لمايكروسوفت** | بلا مفتاح ومجاني؛ يتطلب `VIRALCUTTER_TTS_ALLOW_NETWORK=1` صراحةً |
| `file` | لا | دبلجة بتسجيلك الخاص، وبلا شبكة |

```powershell
python -m scripts.dubbing --providers
python -m scripts.dubbing --project VIRALS\my-project --provider edge --voice ar-EG-ShakirNeural
```

**الانضباط المضمَّن:**
- مزوّد الشبكة **مرفوض افتراضياً** — لا يخرج نص من جهازك بلا إذن صريح.
- **فشل مفتوح لكل سطر:** فشل سطر يُتخطّى ويُسجَّل؛ فشل الكل ⇒ لا ملف ناتج والمقطع الأصلي كما هو.
- **ملاءمة زمنية** بـ`atempo` داخل نافذة كل سطر (0.5×–3×، والزيادة تحذير).
- **فحص ذاتي ضد الدوبلاج الصامت** + `media_validation` قبل تبنّي الناتج + كتابة ذرّية.
- **لا تجاوز للبوابة:** اختبار يثبّت أن الدبلجة لا تلمس `upload_gate` إطلاقاً.
- التقرير يحمل `synthetic_voice`/`disclosure_required` — يوتيوب يطلب الإفصاح، والمدبلج
  تحويل جوهري مشروع لا أصل جديد.

الدليل: `docs/DUBBING_AR.md`.

## 2) قناة تحديث لا تحتاج GitHub Releases — `scripts/update_manifest.py`

**المشكلة (#27):** المستودع خاص ⇒ المحدّث لا يرى الإصدارات ⇒ لا يوجد تحديث تلقائي أصلاً.

**الحل:** manifest موقَّع تنشر فيه البرنامج في **أي مكان**:

```powershell
python -m scripts.update_manifest create --version 7.50.0-pro `
  --windows dist\OUSSAMA-Cutter.exe --base-url https://example.com/dl `
  --out dist\update_manifest.json --sign --key keys\maintainer-signing.key
```

والعميل: `VIRALCUTTER_UPDATE_CHANNEL=manifest` + `VIRALCUTTER_UPDATE_MANIFEST=<رابط>`
+ `VIRALCUTTER_UPDATE_PUBLIC_KEY=<مفتاح عام>`.

سلسلة الثقة: **توقيع ← manifest ← sha256 ← البرنامج**. وفشل مغلق: غير موقَّع ⇒ مرفوض،
بلا مفتاح ⇒ مرفوض، معدَّل ⇒ مرفوض، لا أصل للمنصة ⇒ مرفوض. قناة GitHub الافتراضية
لم تتغيّر إطلاقاً.

الدليل: `docs/UPDATE_CHANNEL_AR.md`.

## ملاحظتان صادقتان

- **خطآن حقيقيان اصطادتهما الاختبارات أثناء التطوير:** عكس منطق `atempo`، وصيغة
  `adelay` بالثواني غير المدعومة في FFmpeg 4.4 التي **كانت تُنتج مساراً صامتاً تماماً
  يمرّ من كل الفحوص**. الاختبارات التي تقيس جهارة الصوت في نوافذ زمنية فعلية هي التي
  كشفتهما — وأُضيف فحص ذاتي دائم يمنع تكرار صمت الدبلجة.
- **Edge TTS لم يُختبر فعلياً على الشبكة** (غير مثبَّت هنا): مساره مرفوض افتراضياً
  ومُتحقَّق من رفضه، أما التوليد الحقيقي فيحتاج تشغيلك مع التفعيل الصريح.
