# درع الحقوق وإعادة الاستخدام

أضيف للمشروع تقرير `provenance_report.json` لكل مشروع. التقرير يفصل بين شيئين:

1. **الحقوق**: تصريح محلي عن الملكية أو الترخيص أو الإذن. هذا ليس تحققاً قانونياً آلياً؛ يجب أن يحتفظ المستخدم بالرابط أو الإثبات الحقيقي.
2. **التحويل التحريري**: لا تعتبر الترجمة أو القص أو إعادة الترميز وحدها قيمة أصلية. يلزم توثيق تعليق أصلي، تعليق صوتي، أو تحليل أصلي؛ ويمكن دعم ذلك بـ B-roll وتحرير جوهري وترجمة.

أنشئ `rights_manifest.json` داخل مجلد المشروع، أو استخدم:

```bash
python -m scripts.provenance --project "مسار/المشروع" --init
```

ثم عدّل الملف إلى قيم حقيقية، مثل:

```json
{
  "basis": "licensed",
  "license": "CC BY 4.0",
  "proof_url": "https://example.com/permission",
  "attestation": true,
  "allow_publish": true
}
```

لتشغيل الدرع الصارم:

```bash
python main_improved.py ... --provenance-gate block
```

في وضع `warn` يظهر التقرير ولا يوقف التصدير. في وضع `block` يرفض بوابة النشر أي مقطع ينقصه تصريح حقوق أو دليل تحويل جوهري. لا يثبت هذا أن المنصة ستقبل المحتوى؛ القرار النهائي يبقى للمنصة وصاحب الحقوق.
