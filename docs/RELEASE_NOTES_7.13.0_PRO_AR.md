# ملاحظات إصدار OUSSAMA Cutter 7.13.0-pro

## الحماية الآلية من مخاطر YouTube

تضيف هذه النسخة طبقة `content_guard` تعمل محلياً وبشكل تلقائي قبل القص وقبل الرفع. تقارن مصدر الفيديو ونافذة المقطع وقائمة المقاطع المنشورة سابقاً، وتستخدم بصمة SHA-256 لملف الفيديو عند توفره. المقطع الذي سبق نشره أو يتداخل بشدة مع نافذة منشورة يُحجب تلقائياً.

كما تمنع النسخة التداخل الشديد بين المرشحين داخل الدفعة نفسها، وتحجب الحالات الدلالية `block` و`review` التي تتضمن تحريضاً أو إقصاءً أو تشبيهاً مهيناً، حتى لا تصل حالة ملتبسة إلى YouTube عبر التشغيل الآلي.

## قاطع دائرة القناة

تُسجل أخطاء السياسة الصريحة مثل `Community Guidelines` أو `strike` أو تعليق/إغلاق القناة في قاعدة SQLite المحلية. عند وجود حادثة مقفلة، يتوقف الرفع الآلي قبل تخزين OAuth أو الاتصال بالمنصة. لا تُقفل القناة تلقائياً بسبب أخطاء quota أو المصادقة العادية؛ تلك أخطاء تقنية تحتاج إصلاحاً مستقلاً.

> لا يقرأ YouTube Data API عدد إنذارات القناة الحالي كحقل عام مضمون. لذلك يبقى القاطع المحلي طبقة احتياطية، ولا يغني عن مراجعة YouTube Studio.

## الملفات الجديدة أو المعدلة

| الملف | الوظيفة |
|---|---|
| `scripts/content_guard.py` | قاعدة البيانات والبصمات وقرارات block وتسجيل النشر وحوادث القناة |
| `scripts/upload_gate.py` | فحص content_guard قبل API وتسجيل النجاح بعد الرفع فقط |
| `main_improved.py` | استبعاد المرشحين المكررين أو الملتبسين قبل القص |
| `webui/publish_panel.py` | توقف مبكر قبل OAuth عند قفل القناة ورسائل عربية للسبب |
| `scripts/project_report.py` | حالة content_guard وقفل القناة في تقرير المشروع |
| `docs/AUTOMATIC_YOUTUBE_SAFETY_AR.md` | دليل التشغيل والحدود والمراجع |
| `tests/test_content_guard.py` | اختبارات التكرار والدلالة والحد اليومي والقاطع |

## التشغيل

من مجلد المشروع على Windows:

```powershell
cd D:\SS
.\.venv\Scripts\python.exe -m scripts.content_guard --project .\VIRALS\اسم_المشروع
.\.venv\Scripts\python.exe -m scripts.project_report --project .\VIRALS\اسم_المشروع --html
```

يبدأ الرفع في وضع Dry Run، وتبقى الخصوصية `private` عند الجدولة. لا يرفع البرنامج شيئاً حقيقياً دون اختيار المستخدم وتأكيد النشر العام عند الحاجة.

## التحقق

أضيفت اختبارات منع البصمة نفسها، ونافذة المصدر نفسها عبر مشروعين، والتداخل داخل الدفعة، والنص الدلالي الملتبس، وحد ثمانية مخرجات ناجحة للمصدر خلال 24 ساعة، وقاطع دائرة أخطاء السياسة، والتوقف قبل OAuth. اجتاز regression الكامل 692 اختباراً، إضافة إلى `ruff check .` و`compileall`.
