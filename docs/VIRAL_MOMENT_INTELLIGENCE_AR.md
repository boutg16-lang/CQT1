# Viral Moment Intelligence — اقتراح نافذة اللحظة

## ما الذي يفعله؟
يضيف طبقة اقتراح زمني حول كل مقطع مفهرس بالتوقيت. افتراضياً يضيف 2.5 ثانية قبل بداية المقطع و3.5 ثانية بعد نهايته، ويحلل النص لاستخراج مؤشرات السؤال والاعتراض والرد وكشف المعلومة والخلاصة. لا يقرر أن المقطع فيروسي ولا يثبت اكتمال الحوار؛ بل يقدّم نافذة أولية قابلة للمراجعة.

## التشغيل

```powershell
python -m scripts.viral_moment_intelligence segments.json --output viral_moments.json
```

المدخل المقبول قائمة JSON أو كائن يحتوي `segments`. كل عنصر يحتاج `start` و`end` (بالثواني) ونصاً في `text` أو `transcript_text`. يمكن تخصيص الهوامش:

```powershell
python -m scripts.viral_moment_intelligence segments.json --lead-in 3 --tail-out 4
```

## حدود السلامة والدقة
- لا يتم تخمين التوقيت إذا كان مفقوداً.
- لا تتغير قيم `start` و`end` الأصلية.
- لا يتم توسيع النافذة اعتماداً على تحليل دلالي غير مثبت.
- يجب مراجعة الصوت والفيديو للتأكد من عدم فصل السؤال عن الجواب أو قطع المتحدث.
- هذه الميزة لا تتنبأ بالانتشار ولا تحكم على صحة المحتوى أو مخالفته لسياسات المنصات.
