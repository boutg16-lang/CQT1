# تخزين مفاتيح Gemini بأمان

لا يكتب OUSSAMA Cutter المفاتيح الجديدة إلى `api_config.json` كنص مكشوف. للحفظ من الواجهة، اضبط عبارة مرور قبل تشغيل البرنامج؛ عند الحفظ تُخزّن المفاتيح مشفّرة في `api_config.secure.json`، وتبقى إعدادات النموذج في `api_config.json` بلا مفاتيح.

## Windows

افتح Command Prompt واضبط عبارة مرور طويلة وفريدة في حساب Windows الحالي:

```bat
setx VIRALCUTTER_CONFIG_PASSPHRASE "ضع-هنا-عبارة-مرور-طويلة-وفريدة"
```

أغلق النوافذ الطرفية المفتوحة وافتحها من جديد، ثم شغّل `run_webui.bat` وأدخل المفاتيح في إعدادات Gemini. سيحفظها البرنامج في التخزين المشفّر. يمكن بدلاً من ذلك ضبط `GEMINI_API_KEY` كمتغير بيئة؛ في هذه الحالة لا يُنسخ المفتاح إلى ملف الإعدادات.

## Linux وmacOS

```bash
export VIRALCUTTER_CONFIG_PASSPHRASE='ضع-هنا-عبارة-مرور-طويلة-وفريدة'
python -m scripts.secure_config --set
```

ألصق المفتاح في المطالبة المخفية. للتحقق من وجود مفتاح، استخدم `python -m scripts.secure_config --get`؛ يعرض قيمة مقنّعة. الخيار `--show-key` يكشف المفتاح صراحةً في الطرفية، فلا تستخدمه في سجلات أو لقطات شاشة مشتركة.

## ترحيل ملف قديم

إذا كان `api_config.json` يحتوي مفتاحاً قديماً، يظل البرنامج قادراً على قراءته ويعرض تنبيهاً بأنه غير مشفّر. اضبط `VIRALCUTTER_CONFIG_PASSPHRASE` ثم احفظ إعدادات Gemini من الواجهة؛ تُنقل المفاتيح إلى الملف المشفّر ولا تُستبدل الإعدادات التالفة أو تُحذف بصمت. إذا لم توجد عبارة مرور، يرفض الحفظ ويُبقي الملف الحالي كما هو.

## حدود الحماية

عبارة المرور لازمة لفك التشفير؛ فقدانها يعني عدم القدرة على استعادة المفاتيح من الملف المشفّر. احتفظ بها في مدير كلمات مرور، ولا تضعها أو المفاتيح في Git أو ملفات ZIP عامة. التشفير يحمي الملف عند التخزين، لكنه لا يحميه من برمجية خبيثة تعمل تحت حساب Windows/Linux نفسه بينما تكون عبارة المرور متاحة في متغيرات البيئة.
