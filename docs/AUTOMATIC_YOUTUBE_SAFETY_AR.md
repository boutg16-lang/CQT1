# الحماية الآلية من مخاطر YouTube في OUSSAMA Cutter

## الهدف

يطبق OUSSAMA Cutter الآن حواجز محلية تلقائية قبل القص وقبل الرفع. الغرض هو تقليل احتمال نشر مقطع مكرر أو محتوى يتضمن تحريضاً على الكراهية أو العنف أو بيانات وصفية مضللة. لا يقدّم النظام ضماناً مطلقاً ضد قرارات YouTube؛ فالقرار النهائي للمنصة يعتمد على المحتوى الكامل والسياق وسجل القناة وعوامل لا يتيحها YouTube Data API دائماً.

> **قاعدة التشغيل:** إذا كان القرار الآلي غير آمن أو كانت الأدلة ناقصة، يوقف النظام المقطع أو الرفع بدلاً من المخاطرة بالنشر.

## ما يحدث تلقائياً

| المرحلة | الفحص الآلي | الإجراء عند الخطر | الأثر المحفوظ |
|---|---|---|---|
| قبل القص | مطابقة نافذة المصدر مع المقاطع المنشورة سابقاً | حذف المرشح من قائمة التصدير | `content_guard_report.json` |
| قبل القص | تحليل النص والعنوان والشرح بقواعد الكراهية والتحريض والسياق | حجب `block` و`review` تلقائياً | التقرير + `viral_segments.txt` المحدث |
| قبل القص | منع التداخل الشديد بين مرشحين في الدفعة نفسها | إبقاء مرشح واحد فقط | سبب `batch_duplicate_window` |
| قبل الرفع | بصمة SHA-256 لملف الفيديو | منع رفع الملف نفسه على المنصة | قاعدة SQLite محلية |
| قبل الرفع | نافذة المصدر والحد اليومي للمصدر | منع إعادة نشر النافذة أو الإنتاج الضخم غير المقصود | سبب القرار والدليل |
| قبل OAuth | قاطع دائرة القناة | إيقاف الرفع قبل الاتصال إذا سُجلت حادثة سياسة | `channel_incidents` |
| بعد نجاح الرفع | تسجيل الملف والمصدر والمنصة والحالة | منع التكرار في التشغيلات التالية | قاعدة SQLite محلية و`publish_history.jsonl` |

## قاعدة بيانات المشروع

يُنشأ الملف `.oussama_content_registry.sqlite3` تلقائياً داخل جذر `VIRALS` في التثبيت المعتاد على Windows، أو داخل المشروع في المشاريع المنعزلة. لا يخزن الفيديو أو التوكنات؛ يخزن البصمات والوقت والمنصة والمسار ونتيجة النشر اللازمة لمنع التكرار.

يمكن تحديد موقع مشترك صراحةً عبر متغير البيئة:

```powershell
$env:OUSSAMA_CONTENT_REGISTRY = 'D:\SS\VIRALS\.oussama_content_registry.sqlite3'
```

لا يتم تسجيل Dry Run أو الرفع الفاشل كنجاح. لذلك لا يؤدي الاختبار الجاف إلى منع رفع حقيقي لاحقاً.

## معنى الحجب الدلالي

تمنع البوابة تلقائياً النص الذي يجمع جماعة محمية مع دعوة عنيفة أو إقصاء أو تشبيه مهين. كما تحجب السياق الملتبس، حتى إذا كان قد يكون خبراً أو مادة تعليمية. السبب أن YouTube يذكر أن السياق التعليمي أو الوثائقي يجب أن يظهر داخل الصوت أو الصور في الفيديو نفسه، ولا يكفي العنوان أو الوصف وحدهما [1]. يستطيع المستخدم إعادة تحرير المقطع أو النص ثم تشغيل المشروع من جديد.

## التكرار والأصالة

تمنع البوابة إعادة نشر ملف الفيديو نفسه، كما تمنع إعادة نشر نافذة المصدر نفسها إذا كانت قد نُشرت على المنصة. وتمنع أيضاً أكثر من ثمانية مخرجات ناجحة من المصدر نفسه خلال 24 ساعة كقاطع حماية من النشر الكمي غير المقصود. هذا ليس حكماً قانونياً على حقوق الملكية، ولا يغني عن امتلاك الحقوق أو إضافة تعليق وتحليل وقيمة أصلية.

تستند هذه القاعدة إلى إرشاد YouTube الذي يطلب أن يكون المحتوى أصلياً، وألا يكون مُنتجاً بكميات كبيرة أو عاماً أو متكرراً أو مخادعاً، كما يميّز بين المحتوى غير الأصلي والمحتوى المعاد استخدامه [2]. وتمنع سياسة المحتوى غير المرغوب فيه الإنتاج الآلي لكميات كبيرة من الفيديوهات المتشابهة والتلاعب الفني المصمم لتفادي الرصد [3].

## قاطع دائرة القناة

إذا أعاد اتصال المنصة خطأً صريحاً يتضمن `Community Guidelines` أو `strike` أو تعليق القناة أو إغلاقها أو مخالفة سياسة، يسجل النظام حادثة ويقفل الرفع الآلي اللاحق. أما أخطاء 401/403 الخاصة بالمصادقة أو 429 الخاصة بالحصّة فلا تقفل القناة تلقائياً؛ فهي تحتاج إصلاح OAuth أو الانتظار وإعادة المحاولة وفق رسالة الخطأ.

لا يدّعي OUSSAMA Cutter أنه يقرأ عدد إنذارات القناة الحالي مباشرةً من YouTube Data API. لذلك يجب اعتبار قاطع الدائرة سجلاً محلياً محافظاً، وليس بديلاً عن مراجعة YouTube Studio. إذا ظهرت في Studio إنذارات أو قيود لا تحتوي عليها رسالة API، أوقف الرفع الآلي يدوياً ولا تعاود النشر حتى تفهم الحالة.

## ملفات التدقيق

| الملف | الوظيفة |
|---|---|
| `content_guard_report.json` | قرارات الحجب قبل القص وأسبابها وأدلتها |
| `.oussama_content_registry.sqlite3` | بصمات ما نُشر وحوادث القناة محلياً |
| `risk_scorecard.json` | درجات التشابه والمحتوى النصي والبصري |
| `publish_blocklist.json` | المقاطع التي لا يسمح لها مسار الرفع |
| `publish_history.jsonl` | سجل عمليات الرفع ونتائجها |
| `project_report.json` | جاهزية المشروع وحالة قاطع القناة |

## التشغيل الآمن على Windows

يبدأ المستخدم من مجلد `D:\SS` ويترك **Dry Run** مفعلاً أثناء الاختبار. بعد اكتمال المعالجة يُراجع `content_guard_report.json` و`risk_scorecard.json` و`project_report.html`. يجب أن تبقى الخصوصية `private` عند الجدولة، ولا يُفعّل `public` إلا إذا كان المستخدم متأكداً من المحتوى ومن تأكيد النشر العام.

```powershell
cd D:\SS
.\.venv\Scripts\python.exe -m scripts.content_guard --project .\VIRALS\اسم_المشروع
.\.venv\Scripts\python.exe -m scripts.project_report --project .\VIRALS\اسم_المشروع --html
```

لا تضع `client_secrets.json` أو `token.json` داخل ZIP ولا ترسلها إلى أي طرف. لا يتم تسجيل الدخول أو الرفع الحقيقي ضمن اختبارات OUSSAMA Cutter الآلية.
