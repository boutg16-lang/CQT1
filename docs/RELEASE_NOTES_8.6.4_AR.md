# OUSSAMA Cutter 8.6.4-ultimate — خطأ Google العابر لا يوقف القص

_التاريخ: 2026-11-14 · النطاق: مرونة التحقق من قناة YouTube_

## 1. العَرَض

```
HttpError 500 when requesting
https://youtube.googleapis.com/youtube/v3/channels?part=id%2Csnippet&mine=true
returned "Internal error encountered."
```

ثم:

```
❌ جاهزية YouTube غير مكتملة؛ تم إيقاف المعالجة قبل التقطيع
```

## 2. السبب

- Google أعاد **500 Internal error** — خطأ مؤقت في خدمته، لا في التوكن
  ولا في الصلاحيات.
- الكود كان يعامل أي استثناء من `channels.list(mine=true)` كفشل إعداد
  نهائي، ويوقف المسار قبل التفريغ والتقطيع.
- التحقق من القناة كان بوابة صلبة حتى عندما لا يوجد رفع مطلوب.

## 3. الإصلاح

### أ. إعادة محاولة ذكية
`YouTubeUploader.verify_channel` يعيد المحاولة **3 مرات** عند:
`429, 500, 502, 503, 504` أو رسائل `Internal error` / `backend error` /
`rate limit`.
- الانتظار: 1.5 ثانية ثم 3 ثوانٍ.
- الأخطاء غير العابرة (400/403 صلاحيات) لا تُعاد ولا تُخفى.

### ب. قرار حسب نية الرفع
بعد استنفاد المحاولات يُرفع `YouTubeTransientError`، والواجهة تقرر:

| الحالة | السلوك |
|---|---|
| رفع فعلي مطلوب | توقف واضح قبل التقطيع، ورسالة «خطأ مؤقت من Google؛ أعد المحاولة أو أوقف الرفع» |
| Dry Run | تحذير + متابعة المعالجة المحلية |
| معالجة محلية فقط | تحذير + متابعة، مع تسجيل الحدث في المشروع |

- لا يُخفى العطل: يظهر في السجل `⚠️ تعذر التحقق من قناة YouTube الآن...`.
- يُسجَّل `youtube_preflight_transient` في أحداث المشروع للمراجعة.
- عند المتابعة المحلية لا يُرفع شيء تلقائياً؛ القرار يبقى للمستخدم.

## 4. ماذا تفعل الآن

### إن كنت على 8.6.0
1. أسرع حل: ألغِ تفعيل «التحقق من اتصال YouTube» أو «الرفع التلقائي» ثم
   أعد المعالجة — القص لا يحتاج YouTube.
2. أو أعد المحاولة بعد دقيقة؛ 500 غالباً عابر.
3. أو حدّث إلى 8.6.4 ليُعاد تلقائياً ويكمل محلياً.

### إن كنت على 8.6.4+
- اتركه: سيعيد المحاولة ثم يكمل محلياً بتحذير.
- إن كان الرفع مطلوباً، انتظر دقيقة وأعد المحاولة؛ لا تُعطّل الحماية.

## 5. التحقق

- `tests/test_youtube_transient_retry.py` — 4 اختبارات:
  - 500 مرتين ثم نجاح → 3 محاولات وانتظار 1.5/3.
  - 500 دائم → `YouTubeTransientError`.
  - 400 → لا إعادة محاولة.
  - عقد المتابعة المحلية.
- المجموعة كاملة خضراء، `ruff` نظيف.

## 6. حدود

- إعادة المحاولة لا تصلح خطأ Google دائماً؛ إن استمر 500 فالمشكلة عند
  المزوّد، لا في CQT1.
- الرفع الفعلي يبقى محمياً: لا تُقطَع مقاطع ثم تفشل كلها في الرفع بصمت.
- إن كان الخطأ 403 أو `insufficientPermissions`، فهذا نطاق OAuth وليس
  خطأً عابراً — الرسالة الحالية تحذف التوكن وتطلب إعادة تسجيل الدخول.
