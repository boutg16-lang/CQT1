# OUSSAMA Cutter 8.0.0 Ultimate — مرشح فرع

هذه حزمة مصدر لمرشح إصدار مبنية على فرع 7.52.2-pro، وليست إصداراً منشوراً أو مدموجاً في GitHub.

## ما تغيّر

- **تقييم أكثر تحمّلاً للبيانات التالفة:** قيم `NaN` و`Infinity` والنصوص غير الرقمية في عوامل التقييم والحدود الصوتية والأوزان لا تعطل اختيار المقاطع ولا تنتج درجات غير صالحة. رُفع `SCORING_VERSION` إلى `8.0.0` لإبطال نتائج الاختيار المخزّنة وفق السياسة السابقة.
- **تحميل WhisperX محدود وآمن:** يسمح الاستثناء غير الآمن فقط لملف VAD الرسمي عند تطابق المسار والتحقق من SHA-256. إذا تعذر تحديد الملف أو التحقق منه، يبقى `weights_only=True` وسياسة الموافقة الصريحة كما هما؛ لا توجد إعادة محاولة غير آمنة تلقائية للملفات الأخرى.
- **مفاتيح Gemini مشفّرة عند الحفظ:** لا تحفظ الواجهة مفاتيح جديدة كنص مكشوف داخل `api_config.json`. يلزم ضبط `VIRALCUTTER_CONFIG_PASSPHRASE` لحفظها مشفّرة في `api_config.secure.json`. تبقى إعدادات المستخدم القديمة قابلة للقراءة، ويُرفض استبدال ملف إعدادات تالف أو الرجوع إلى نص مكشوف عند فشل التشفير.
- **CLI أكثر أماناً:** يطلب `python -m scripts.secure_config --set` المفتاح بإدخال مخفي، ويرفض تمريره كوسيط أمر. يعرض `--get` نسخة مقنّعة؛ كشف القيمة الكاملة يتطلب `--show-key` صراحةً.
- فحوص اتصال Gemini ترسل المفتاح في ترويسة المصادقة بدلاً من عنوان الطلب، وتحجب بيانات الاعتماد من رسائل الأخطاء.
- حزمة الدبلجة الاختيارية متاحة عبر `uv sync --extra dubbing`؛ تبقى مشاركة النص مع Edge TTS معطلة ما لم يُفعّل المستخدم الشبكة.
- **توضيح واجهة وإرشادات المفتاح:** أضيفت رسالة الحفظ المشفّر إلى اللغات الأربع، ووُثّق الإعداد والترحيل والحدود في `docs/SECURE_API_KEYS_AR.md`.
- **حزمة مصدر نظيفة:** لا تتضمن مفاتيح أو إعدادات جهاز أو سجلات أو قاعدة بيانات محلية أو وسائط مستخدم. تُستبعد كذلك بيئات Python المؤقتة ومخرجات البناء والاختبار.

## التحقق المنفذ

- مجموعة الاختبارات كاملة: **2,287 ناجحاً، و2 متخطّيان**.
  - اختبار OpenTimelineIO تخطّاه لأن الاعتمادية الاختيارية غير مثبتة.
  - اختبار PowerShell تخطّاه لأنه يتطلب Windows.
- Ruff: `ruff check --no-respect-gitignore .` — ناجح.
- `compileall` للـ`main_improved.py` و`app_version.py` ومجلدي `scripts/` و`webui/` — ناجح.
- `uv lock --check --offline` — ناجح.
- فحص `preflight --check --json` أعاد الحالة **2 (تحذيرات فقط، بلا عناصر حرجة)**: ملف `api_config.json` والنماذج وتهيئة Telegram غير موجودة في حزمة المصدر؛ وWhisperX وPyTorch وميزات الرفع و`edge-tts` اعتمادات اختيارية غير مثبتة. كان FFmpeg وFFprobe والأصول وقائمة السلامة سليمة.

## حدود هذا المرشح

- لم يُختبر على Windows فعلي أو بطاقة RTX 3060، ولم يُشغّل على فيديو إنتاجي طويل. لا يُعد نجاح الاختبارات الآلية بديلاً عن مراجعة بشرية قبل استخدامه مع محتوى حقيقي.
- هذا التحديث يركّز على أمان الإعدادات، موثوقية التقييم، وسلامة الحزمة؛ لا يدّعي إعادة تصميم كاملة للواجهة أو التحقق من جودة قصّ نموذج على الفيديو.
- لم يُرفع أي فيديو، ولم يحدث نشر أو دمج أو إنشاء وسم إصدار في GitHub.

## الإعداد الآمن

راجع `docs/SECURE_API_KEYS_AR.md`. لا تضع `api_config.json` أو `api_config.secure.json` أو عبارة المرور داخل Git أو ملف ZIP عام. فقدان عبارة المرور يمنع استعادة المفاتيح من المخزن المشفّر.
