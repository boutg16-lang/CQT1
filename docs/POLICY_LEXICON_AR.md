# قاعدة كلمات وسياسة YouTube

لا توجد قائمة رسمية ثابتة من YouTube اسمها «الكلمات الممنوعة». القرار يعتمد على العبارة كاملة، الهدف، المجموعة المحمية، النبرة، والسياق التعليمي أو التوثيقي. لذلك لا يحذف النظام كلمة منفردة تلقائياً؛ بل يربط التطابق بالفئة والخطورة والمصدر ويترك الحالات الملتبسة للمراجعة.

## ما أُضيف

- قاعدة SQLite محلية: `.oussama_policy_lexicon.sqlite3`.
- جدول `policy_terms` للكلمات والعبارات باللغات والفئات والخطورة والمصدر.
- جدول `policy_sources` لحفظ روابط سياسات YouTube الرسمية وتاريخ المزامنة.
- بحث FTS5 سريع للتدقيق المحلي.
- مزج القائمة المدمجة مع حزمة `safety_blocklist_cache.json` التي يحدثها `safety_updater.py`.
- حفظ مصدر كل مصطلح؛ لا تُعامل حزمة مجتمع أو ملف مخصص كأنه قائمة رسمية من YouTube.

## أوامر مفيدة

```bash
python -m scripts.policy_lexicon --project /path/to/project --sync
python -m scripts.policy_lexicon --project /path/to/project --search "hate"
```

يمكن نقل القاعدة إلى مكان مركزي لكل المشاريع عبر المتغير `OUSSAMA_POLICY_DB`. هذا لا يغني عن فحص النص الكامل والصوت والصورة، ولا يضمن قرار YouTube النهائي.

## السياسة العملية

- **حظر تلقائي:** تحريض صريح على العنف أو نزع الإنسانية مع استهداف مجموعة محمية، عندما يدعمها السياق.
- **مراجعة بشرية:** شتيمة أو كلمة حساسة بلا سياق كافٍ، أو مادة إخبارية/وثائقية قد تنطبق عليها استثناءات EDSA.
- **سماح:** ذكر تعليمي أو نقدي واضح لا يتبنى الكراهية.

المراجع الرسمية محفوظة داخل قاعدة البيانات، ومنها سياسة خطاب الكراهية وسياسة الإرشادات المجتمعية في YouTube.
