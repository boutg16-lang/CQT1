# حارس البثّ المباشر — `stream_guard`

أداة محلية لفحص ترجمة البثّ ودردشته بعد انتهاء البثّ، ثم إخراج نوافذ خطر وتقرير للمراجعة. لا تعمل تلقائيًا في الخلفية، ولا تستبدل بوابات `safety_filter` أو `content_guard` أو `upload_gate`.

## طريقة العمل

1. `check` يحمّل ترجمة YouTube والدردشة عبر `yt-dlp` لبثّ أو قناة.
2. يفحص ملفات الترجمة/الدردشة بطبقتين نصيتين: معجم `stream_guard` (391 عبارة و201 مجموعة سياقية)، ثم `safety_filter` الموجود في المشروع (336 مصطلحًا أساسيًا، مع التخصيصات المحلية وقاعدة السياسات المخزنة مؤقتًا). الفحص المحلي لا يزامن قواعدًا عبر الشبكة.
3. يكتب `risk_windows.json` و`safe_windows.json` مع النوافذ الزمنية، و`report.json` الكامل، إضافة إلى `report.html` و`report.md` للمراجعة. قد يعرض HTML/Markdown أول 150/120 رسالة دردشة فقط لتجنّب تقارير ضخمة؛ السجل الكامل موجود في `report.json`. تُكتب ملفات JSON ذريًا حتى لا تترك عملية مقطوعة ملفًا جزئيًا.
4. عند تشغيل `apply` صراحةً، تُحذف من `viral_segments.txt` المقاطع التي تتقاطع مع نوافذ الخطر بعد توسيعها بهامش الأمان. تُحفظ النسخة الأصلية في `viral_segments.txt.bak`، أو في أول اسم احتياطي غير مستخدم (`.bak.1` وهكذا).

هذا **ليس تكاملًا تلقائيًا قبل اختيار المقاطع**: `watch` يراقب قناة وينشئ التقارير بعد انتهاء البثّ، لكن تطبيق الحذف يتطلب أمر `apply` صريحًا. راجع التقرير يدويًا قبل تطبيقه؛ التفريغ الآلي قد يخطئ في الفصحى أو الدارجة الجزائرية، وقد ينتج إنذارات كاذبة أو يفوّت سياقًا لا يظهر في النص.

## الاستخدام

```bash
# فحص فيديو أو بثّ منتهٍ
python -m scripts.stream_guard check https://www.youtube.com/watch?v=VIDEO_ID

# مراقبة قناة؛ يفحص البثّ بعد انتهائه
python -m scripts.stream_guard watch https://www.youtube.com/@ChannelName

# فحص ملفات ترجمة/دردشة محلية دون تنزيلها
python -m scripts.stream_guard scan path/to/transcript.srt path/to/live_chat.json --out stream_reports/local-run

# تطبيق النوافذ بعد مراجعتها
python -m scripts.stream_guard apply stream_reports/VIDEO_ID/risk_windows.json --project path/to/project
```

يمكن تغيير مستوى الشدة والفاصل الزمني بواسطة `--min-severity` و`--gap` في أوامر `check` و`scan`. يوسّع `apply` النوافذ ثلاث ثوانٍ من كل طرف افتراضيًا؛ غيّر ذلك فقط بعد فحص التقرير باستخدام `--margin`.

## المخرجات

- `report.json`: السجل الكامل لكل المطابقات ورسائل الدردشة، دون حدّ العرض.
- `report.html` و`report.md`: المطابقات وسياقها وأسبابها؛ بيانات النص الواردة من الملفات تُهَرَّب في HTML وMarkdown. عند كثرة رسائل الدردشة تُعرض عيّنة محدودة، ويظل السجل كاملًا في `report.json`.
- `risk_windows.json`: المصدر، المدة، `windows` الخطرة، و`safe_windows` المحسوبة.
- `safe_windows.json`: النوافذ المكملة التي لا تتقاطع مع الخطر المكتشف؛ ليست ضمانًا أن بقية الفيديو آمن.
- `apply`: لا يغيّر ملف المشروع عند غياب النوافذ أو عند فساد ملف المخاطر؛ عند وجود تقاطع يكتب JSON جديدًا ذريًا ويحفظ نسخة احتياطية لا يستبدل نسخة سابقة.

التقارير تحفظ مقتطفات التفريغ وأسماء أصحاب الرسائل محليًا؛ لا تضعها في مستودع عام أو مجلد مشاركة.

## حدود الاختبار

أمر `scan` يفحص ملفات محلية دون تنزيلها أو مزامنة قواعد السياسات عبر الشبكة. الأداة نصية فقط: لا تحلل الصوت أو الصورة مباشرة، ولا تستخرج تفريغًا جديدًا إذا لم يوفّر YouTube ترجمة. `watch` مراقب دوريّ يعمل ما دامت العملية مفتوحة؛ لا ينشئ خدمة دائمة أو مهمة مجدولة.
