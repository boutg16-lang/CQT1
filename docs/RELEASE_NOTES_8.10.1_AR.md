# OUSSAMA Cutter 8.10.1-ultimate — السجل يعرض التقدّم بدل أن يتجمّد

_التاريخ: 2026-11-14 · النطاق: تشغيل التفريغ الصوتي وتحميل النماذج_

## 1. ما رأيته

```
النسخ الصوتي باستخدام النموذج large-v3-turbo...
Warning: You are sending unauthenticated requests to the HF Hub...
```

ثم لا شيء. لا خطأ، لا شريط تقدّم، ولا نهاية — لساعات أو أيام. المشروع
لم يكن ميتاً بالضرورة؛ كان **يحمّل النموذج** والتطبيق لا يعرض ما يحدث.

## 2. السبب

### أ. `readline()` لا يرى `\r`
Hugging Face وtqdm يحدّثان سطر التقدّم بـ`\r` (رجوع للبداية) لا `\n`.
WebUI كان يقرأ بـ`readline()`، أي ينتظر `\n`. النتيجة: كل تحديثات
التحميل تُخزَّن ولا تظهر حتى ينتهي التحميل بالكامل. يبدو البرنامج معلّقاً.

### ب. Xet قد يتوقّف على Windows
`huggingface-hub` الحديث يستخدم Xet للتنزيل المتوازي. خلف بروكسي أو شبكة
مصفّاة قد ينتظر بلا نهاية بدل الرجوع إلى HTTP.

### ج. الكاش الجديد فارغ
بعد نقل النماذج إلى `D:\OS\.models`، أول تشغيل يعيد تحميل نموذج
`large-v3-turbo` (~1.6 GB) حتى لو كانت النسخة القديمة في
`C:\Users\PC\.cache`.

## 3. الإصلاح

- قارئ سجل جديد يفصل على `\r` و`\n` معاً، ويقرأ حرفاً حرفاً حتى تظهر
  الأسطر فوراً (لا ينتظر امتلاء المخزن).
- كل نبضة تقدّم (كل 15 ثانية) تُضاف إلى السجل ظاهرة:
  `⏳ جاري تحميل نموذج WhisperX ... — 45ث`.
- تعطيل أشرطة tqdm/Hugging Face في عملية الابن، وتشغيل نبضتنا بدلاً منها.
- `HF_HUB_DISABLE_XET=1` افتراضياً، و`HF_HUB_DOWNLOAD_TIMEOUT=60`.
  للعودة إلى Xet: `set VIRALCUTTER_ENABLE_XET=1`.
- preflight يوضّح حالة الكاش: فارغ (معلومة) أو قديم مهجور (تحذير مع أمر
  النقل).

## 4. على جهازك

```powershell
cd D:\OS
.\update_project.bat
.\run_webui.bat
```

إن كان الكاش القديم مليئاً وتريد تفادي إعادة التحميل:

```powershell
.\.venv\Scripts\python.exe -m scripts.model_paths --migrate
```

ثم أعد التشغيل. سترى أثناء التحميل:

```
⏳ جاري تحميل نموذج WhisperX large-v3-turbo وVAD — 30ث
```

## 5. تشخيص سريع إن بقي متوقفاً

اختبر الشبكة وحدها في نافذة PowerShell منفصلة:

```powershell
.\.venv\Scripts\python.exe -c "from huggingface_hub import hf_hub_download; print(hf_hub_download('Systran/faster-whisper-large-v3-turbo','config.json'))"
```

- إن علّق هذا الأمر أيضاً: الشبكة/البروكسي هو المشكلة، لا التطبيق.
- إن نجح بسرعة: المشكلة في نموذج VAD المحمي. شغّل بمسار
  faster-whisper:
  ```powershell
  set VIRALCUTTER_TRANSCRIPTION_BACKEND=faster-whisper
  .\run_webui.bat
  ```
