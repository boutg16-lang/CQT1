# OUSSAMA Cutter 8.2.0-ultimate — مزوّدون مفتوحون وتشابه دلالي

_التاريخ: 2026-11-13 · النطاق: طبقة LLM، إزالة التكرار، فحص العناوين العربية_

## 1. لماذا هذه الدفعة

المشروع كان يعمل مع Gemini أو g4f أو ملف GGUF محلي فقط. في 2026 صار
كل شيء تقريباً — Ollama، LM Studio، vLLM، llama.cpp server، OpenRouter،
Groq، Together، DeepSeek — يتحدث نفس واجهة OpenAI:
`/v1/chat/completions` و`/v1/embeddings`. مشروع واحد صغير يفتح كل هؤلاء
بلا اعتماد جديد، ويمنح من لا يريد إرسال نصوصه إلى Google خياراً محلياً كاملاً.

الأدوات المفتوحة المنافسة (openshorts، SupoClip، Clips Kitty) تعتمد بالفعل
على Ollama أو OpenRouter. تأخّر CQT1 في هذه النقطة كان يكلّف المستخدم
اشتراكاً أو ربطاً سحابياً إجبارياً.

## 2. الإعداد

### Ollama محلياً (بلا مفتاح)

```bash
ollama pull qwen2.5:7b
ollama pull bge-m3          # اختياري للتضمينات
python main_improved.py --ai-backend openai --openai-base-url http://localhost:11434/v1 --ai-model-name qwen2.5:7b --skip-prompts --input-video input.mp4
```

### OpenRouter أو Groq أو أي مزوّد سحابي

```bash
export OPENAI_BASE_URL=https://openrouter.ai/api/v1
export OPENAI_API_KEY=sk-...
python main_improved.py --ai-backend openai --ai-model-name google/gemini-2.5-flash --skip-prompts ...
```

يمكن وضع نفس القيم في `api_config.json`:

```json
{
  "selected_api": "openai",
  "openai": {
    "base_url": "http://localhost:11434/v1",
    "api_key": "",
    "model": "qwen2.5:7b",
    "chunk_size": 12000,
    "embedding_model": "bge-m3",
    "embeddings": true
  }
}
```

أولوية القراءة: متغيّر البيئة، ثم `api_config.json`، ثم الافتراضي (Ollama محلي).
المفتاح لا يُكتب في argv ولا في السجلات؛ في الواجهة يُمرَّر للعملية الابن
عبر البيئة ولا يُحفظ كنص مكشوف.

## 3. التضمينات (اختيارية)

```bash
export VIRALCUTTER_EMBEDDINGS=1
export VIRALCUTTER_EMBEDDING_MODEL=bge-m3
```

عند التفعيل:

- تُضمَّن كل نصوص المقاطع المختارة دفعة واحدة بعد بناء المرشحين.
- تُستخدم في كشف التكرار الدلالي، وعقوبة التكرار، وترتيب التنوّع.
- تُخزَّن في ذاكرة مؤقتة محدودة (1024 نصاً)، فلا يُعاد تضمين النص نفسه.
- أي فشل (نموذج غير محمّل، خادم متوقف، بُعد متجه خاطئ) يعود للمقارنة
  النصية الحالية ويطبع سبباً واحداً — لا يوقف المشروع.
- لا تُحفظ المتجهات في `viral_segments.txt`.

المثال الذي تعجز عنه المقارنة السطحية:

| المقطع | النص |
|---|---|
| A | الصبر يصنع النتيجة |
| B | الاستمرارية هي التي توصل |

بلا تضمينات: تشابه رمزي منخفض → مقطعان. مع `bge-m3`: تشابه عالٍ → مقطع واحد.
يبقى حارس الأرقام: إذا ذكر المقطعان رقمين مختلفين فهما ليسا تكراراً.

## 4. جذور العربية في فحص العناوين

`arabic_text.light_stem` يجرّد سابقة واحدة ولاحقة واحدة بأمان:

| الكلمة | الجذر للمقارنة |
|---|---|
| وإتقانها | اتقان |
| إتقان | اتقان |
| بالنجاح | نجاح |
| الاستمرارية | استمراري |
| المهارة | مهار |
| كتابان | كتاب |
| برنامج | برنامج (لا يُمسّ) |

النتيجة: عنوان «إتقان مهارة» على مقطع يقول «وإتقانها…» لم يعد يُرفض كادعاء
غير مدعوم. التجريد للمقارنة فقط؛ النص المعروض والمحفوظ يبقى كما هو.

## 5. ما تم فحصه من مشاريع خارجية

| المشروع | الترخيص | القرار |
|---|---|---|
| [openshorts](https://github.com/mutonby/openshorts) | MIT | أفكار فقط: كشف لحظات متعدد الوسائط، ترتيب، دبلجة. البنية مختلفة ولا يُنسخ الكود. |
| [SupoClip](https://github.com/FujiwaraChoki/supoclip) | مفتوح | لا دمج: تكرار لوظائف موجودة (قص، ترجمة، إعادة تأطير). |
| [Clips Kitty](https://github.com/ColinGPT9/clips-studio) | مفتوح | أكد قيمة OpenAI-compatible + Ollama؛ adopted كطبقة مزوّدين، لا ككود. |
| [Tashaphyne](https://github.com/linuxscout/tashaphyne) | GPL | متوافق مع GPL-3.0، لكنه يجلب pyarabic معه. أُخذ المبدأ ونُفّذ تجريد خفيف داخلي بلا اعتماد. |
| [Silero VAD](https://github.com/snakers4/silero-vad) | MIT | يبقى مرشحاً لتحسين jump cuts بعد benchmark عربي؛ لم يُدمج بعد. |

لا كود خارجي نُسخ في هذه الدفعة. كل ما أُضيف مكتوب داخل المشروع ومُختبر.

## 7. حدود

- التضمينات تحتاج خادم تضمينات فعلياً؛ إن لم يوجد النموذج يعود المشروع
  للمقارنة النصية بهدوء.
- `chunk_size` الافتراضي للمزوّد المفتوح 12000 حرف لأن سياق النماذج المحلية
  أصغر من Gemini؛ يمكن رفعه من الإعدادات.
- لم يُشغَّل مسار GPU/Windows فعلي في هذه الدفعة، ولا نموذج سحابي حقيقي
  (الاختبارات تحاكي HTTP).
