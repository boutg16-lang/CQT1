# تطبيق OUSSAMA Cutter Android

يحتوي المشروع على عميل Android/Compose اختياري داخل `app/`. العميل الحالي يوفر واجهة المراجعة والحماية والتحليل المحلي، ولا يضم مفتاح Gemini داخل APK.

## البناء المحلي

يتطلب البناء JDK 21 وAndroid SDK API 36 وBuild Tools 36.0.0:

```bash
./gradlew --no-daemon lintDebug testDebugUnitTest assembleDebug
```

ملفات Gradle المولدة والكاش المحلي وملفات التوقيع مستبعدة من Git.

## Gemini

لا يقرأ التطبيق أي مفتاح من `BuildConfig` ولا يدمج مفتاحًا في الحزمة. يمكن للمستخدم إدخال مفتاحه مؤقتًا من شاشة الإنشاء؛ يُحفظ في الذاكرة فقط ويُرسل عبر ترويسة `x-goog-api-key` إلى HTTPS. للاستخدام الإنتاجي يوصى بوضع Gemini خلف Backend يملك rate limiting وقيود نطاق ومراقبة، بدل توزيع مفاتيح المستخدمين.

عند غياب المفتاح يعمل التحليل المحلي المحدود، لكن النتائج تبقى غير معتمدة وتتطلب مراجعة صريحة قبل النشر.

## التوقيع

لا يستخدم Release مفتاح Debug. بناء Release الناتج غير موقع ما لم يُضف توقيع إنتاجي خارج المستودع عبر نظام أسرار CI. يمنع منعًا باتًا تخزين `.jks` أو `.keystore` أو كلمات مرور التوقيع في Git.

## حدود النسخة الحالية

العميل Android لا ينفذ بعد تنزيل الفيديو، WhisperX، فحص حقوق النشر، أو Loudness QC بشكل مستقل. لذلك تبقى هذه النتائج `pending` ولا يسمح التطبيق باعتبارها اجتازت الفحص تلقائيًا.
